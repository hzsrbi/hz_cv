# Hormoz Sohrabi — Academic CV website

A responsive, build-free website prepared from CV_Eng-20260918(1).pdf.

## Publish with GitHub Pages

1. Sign in to GitHub and create a public repository named `YOUR-USERNAME.github.io`, replacing YOUR-USERNAME with your actual GitHub username. If that repository already exists, use a new repository such as `cv` instead of overwriting it.
2. Unzip this package. Upload all files **inside** `cv-website` to the repository root. Preserve the `assets` folder. `index.html` must be at the root, not inside another folder.
3. Open repository Settings → Pages. Under Build and deployment select Deploy from a branch, then branch `main` and folder `/ (root)`. Save.
4. Your address will be `https://YOUR-USERNAME.github.io/`, or `https://YOUR-USERNAME.github.io/cv/` for a repository named `cv`.

## Update

Edit `index.html` to change content, `style.css` for design, and replace `assets/Hormoz_Sohrabi_CV.pdf` for the downloadable CV. No installation or build is required. Publication search runs locally in the browser.
